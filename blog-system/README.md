# Blog System

A blog website built with Next.js (App Router), React, TypeScript, and MUI.

## Prerequisites

- Node.js 20+
- npm 10+

## Install Dependencies

From the `blog-system` folder:

```bash
npm install
```

## Run in Development

```bash
npm run dev
```

Then open:

- http://localhost:3000

## Useful Local Routes

- Home: http://localhost:3000
- Admin login: http://localhost:3000/admin/login
- Admin dashboard: http://localhost:3000/admin
- Admin comments: http://localhost:3000/admin/comments
- Blog detail example: http://localhost:3000/blog/1

## Production Build

Build the app:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

## Lint

```bash
npm run lint
```

## Project Scripts

- `npm run dev`: start development server
- `npm run build`: create production build
- `npm run start`: run production server
- `npm run lint`: run ESLint
